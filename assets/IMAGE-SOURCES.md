# 홈 대표 이미지

- 출처: 실버팰리스 공식 한국어 사이트 https://silverpalace.elementagames.com/ko-kr/news
- 원본: https://s.elementagames.com/uploads/file/20260624/3ae4043903b25b0ac443b70209ce4c06.jpg
- 용도: 비공식 가이드 홈 화면 대표 이미지
- 변경: WebP 변환 및 크기 축소. 화면 너비에 따른 CSS 크롭.
- 이미지의 권리는 원저작권자에게 있습니다. 이 저장소의 코드와 별도로 취급합니다.

## 워드마크

기존 승인 이미지 「실버 스트림 우아한 워드마크.png」를 사용합니다. 투명 여백만 정리하고 비율을 유지하여 WebP로 변환했습니다. 밝은 배경에서는 CSS로 단색 잉크색을 표시하고 어두운 배경에서는 원본 색을 유지합니다.
