# Silver Palace Guide

실버팰리스 비공식 종합 가이드. 비공개 저장소에서 이용자 사이트와 관리 사이트를 함께 관리합니다.

## 로컬 실행

Node.js 22 이상. 외부 패키지 설치 없이 실행됩니다.

```sh
npm run check
npm run build
npm run dev
```

- 이용자 홈: http://localhost:4321/
- 관리 화면: http://localhost:4321/admin/

## 구조

- `apps/site/`: 이용자용 홈 템플릿
- `apps/admin/`: 관리자용 로컬 편집 화면
- `content/home.json`: 현재 빌드에 반영되는 홈 문구
- `scripts/`: 검증·빌드·로컬 서버
- `.local/`: 로컬 초안. Git에 저장하지 않습니다.
- `dist/site/`, `dist/admin/`: 독립적인 빌드 출력

## 구현 범위

이용자 홈, 반응형 화면, 테마 전환, 메뉴 제목 검색. 관리 화면에서 홈 문구 편집, 파일 기반 로컬 초안 저장, 미리보기, JSON 내보내기·가져오기. 도감과 계산기는 준비 중 안내만 제공합니다.

초안 저장은 `content/home.json`이나 공개 사이트를 바꾸지 않습니다. 원본 불러오기는 현재 편집 내용만 변경합니다. 공개 배포 버튼은 아직 비활성 상태입니다.

## 다음 연결 단계

1. Cloudflare에서 이용자 사이트와 관리자 사이트를 별도 프로젝트로 구성합니다.
2. 관리자 접근 인증과 서버 측 권한 검증을 구현합니다. `scripts/dev.mjs`는 개발 전용이며 외부에 배포하지 않습니다.
3. 관리자 서버에서 GitHub의 초안 브랜치에 변경을 기록합니다. 브라우저에 토큰·Deploy Hook을 전달하지 않습니다.
4. 공개 배포 시 검증을 마친 특정 변경을 공개용 브랜치에 반영하고 이용자 사이트 빌드를 요청합니다.
5. 배포 상태와 실패·복원 이력을 표시합니다. 일반 초안 저장으로 공개용 빌드를 실행하지 않습니다.

두 사이트에는 각각 필요한 산출물만 배포합니다. 이용자 사이트에 관리 코드·초안·인증 정보를 포함하지 않습니다. 관리자 정적 화면만 호스팅해도 실제 편집·배포 API는 작동하지 않습니다.

게임 수치·이미지는 아직 수록하지 않았습니다. 게임 권리와 팬 사이트 코드는 구분해 관리합니다.
